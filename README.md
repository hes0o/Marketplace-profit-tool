# Marketplace Profit Tool

- A tool that shows Trendyol sellers their true net profit per order and per product, after commission, shipping, returns and VAT.

- Trendyol satıcılarına komisyon, kargo, iade ve KDV sonrası sipariş ve ürün bazında gerçek net karı gösteren bir araç.

## How to run / Nasıl çalıştırılır

1. Install Node.js 22 LTS or newer and pnpm (`npm install -g pnpm`).
2. Clone the repo and open the folder.
3. Run `pnpm install`.
4. Run `pnpm dev`.
5. Open http://localhost:3000 and you should see "Hello from shared".

TR: Node.js 22 LTS veya üstünü ve pnpm'i kurun, `pnpm install` ardından `pnpm dev` çalıştırın, sonra http://localhost:3000 adresini açın.
