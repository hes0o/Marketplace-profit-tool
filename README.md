# Marketplace Profit Tool

- A tool that shows Trendyol sellers their true net profit per order and per product, after commission, shipping, returns and VAT.

- Trendyol satıcılarına komisyon, kargo, iade ve KDV sonrası sipariş ve ürün bazında gerçek net karı gösteren bir araç.
